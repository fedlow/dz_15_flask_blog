# 🔐 Блог с авторизацией (ДЗ №15: Маршрутизация, URL и работа с API)

Учебное веб-приложение-блог на микрофреймворке **Flask**, дополненное системой регистрации и авторизации пользователей с использованием токенов.

## 📝 Описание проекта
Приложение расширяет функционал блога из предыдущего ДЗ. Теперь для доступа к записям дневника и главной странице требуется авторизация.
Реализованы следующие возможности:
1. **Страница `/home`** — стартовая точка с кнопками «Регистрация» и «Вход».
2. **Страница `/register`** — форма регистрации (логин, email, пароль). Пароли хешируются перед сохранением в БД.
3. **Страница `/login`** — форма входа. При успешной проверке данных генерируется токен, который сохраняется в сессии.
4. **Защита маршрутов** — главная страница (`/`) и дневник (`/notes`) доступны только авторизованным пользователям. Если токен отсутствует или просрочен (по умолчанию живет 1 час), пользователь перенаправляется на страницу входа.
5. **Выход из системы** — кнопка «Выйти» очищает сессию.

## 🛠️ Технологии
* **Python 3**
* **Flask** (микрофреймворк)
* **Flask-SQLAlchemy** (ORM для работы с БД)
* **Flask-Migrate** (миграции БД)
* **Werkzeug** (хеширование паролей)
* **ItsDangerous** (генерация и проверка токенов)
* **SQLite** (база данных)
* **HTML5, CSS3, Jinja2** (шаблоны)

🚀 Как запустить проект локально

Установите зависимости:

pip install flask flask-sqlalchemy flask-migrate

Примените миграции (чтобы создать таблицы User и Notes):

flask db upgrade

Запустите приложение:

python app.py

Откройте браузер и перейдите по адресу: http://127.0.0.1:5000/home
